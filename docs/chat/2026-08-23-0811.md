## Maximum-fidelity viewer audit findings

Added `docs/VIEWER_RENDER_PIPELINE_AUDIT.md`.

Commit:

- `267c205c3f4d3bb3a63323727685e15e5f223d3e`.

### Existing upstream strengths discovered

Aves already has more of the correct 1:1/LOD foundation than initially assumed:

- `originalScale = 1 / devicePixelRatio`;
- an `originalSize` scale state;
- DPR-aware tile sample-size selection;
- at physical 1:1, sample size resolves to 1, so full source-resolution tile pixels are requested.

This changes the task from inventing physical 1:1 scaling to validating/refining it.

### Strict 1:1 gap

At the physical 1:1 condition, current raster rendering still selects `FilterQuality.high` rather than an explicitly unfiltered pixel path.

Planned strict Pixel Inspector mode therefore adds:

- guaranteed sample-size-1 data;
- explicit nearest/unfiltered sampling;
- physical pixel alignment/snapping;
- diagnostics proving source-pixel-to-panel-pixel ratio.

### Major fidelity bottleneck discovered: region decoder

Android `RegionFetcher` currently requests:

- `Bitmap.Config.ARGB_8888`;
- `ColorSpace.Named.SRGB`.

This creates a real 8-bit/sRGB choke point in the tiled large-image path.

### Major fidelity bottleneck discovered: raw pixel bridge

`BitmapUtils.getRawBytes()` currently connects normal output to sRGB and converts normal:

- RGBA_F16 -> ARGB_8888;
- RGBA_1010102 -> ARGB_8888;
- wide-gamut ARGB_8888 -> sRGB ARGB_8888.

This is a P0 Reference-fidelity target.

### Useful existing bridge capability

Dart `InteropDecoding.rawBytesToDescriptor()` already recognizes:

- RGBA8888;
- RGBA1010102;
- RGBA float32.

1010102 is expanded to Flutter float32. This means we can likely upgrade the native transport rather than replace the entire viewer.

### Ultra HDR hook already exists

Aves has:

- `PlatformMediaFetchService.applyHdrGainmap`;
- `applyGainmap` passed to Android region fetching;
- `GainmapUtils` manual reconstruction using Android gain-map metadata;
- float32 output when applying the gain map.

This existing path will be validated/reworked rather than discarded or blindly trusted.

### Exact Flutter shader capability verified

The fork pins Flutter submodule commit:

`7c7929adb0767c020659a422ae86df9ec0d5f82a`.

That exact SDK supports Impeller `ImageFilter.shader`, runtime support detection, `FragmentProgram.fromAsset`, and named shader uniforms.

Planned live-preview rule:

- pointwise edits can use this path after the color-space contract is fixed;
- untouched Reference rendering bypasses the filter completely;
- spatial operations such as Structure/Tonal Contrast/local Ambiance will not be faked as zoom-dependent screen-space effects.
